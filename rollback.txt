
版本回退

git log：显示最近到最远的提交日志。
"commit id"：git的版本号。

HEAD：表示当前版本。
HEAD^(表示上一个版本)，HEAD^^(表示上上个版本)，往上100个版本就是100个^，也可写成“HEAD~100”。

git reset：把当前版本回退到上一个版本。
--hard：回退到上个版本的已提交状态（仓库、暂存区、工作区全部强制覆盖）；
--soft：回退到当前版本的已添加未提交状态（工作区、暂存区代码不变）；
--mixed:回退到当前版本的未添加状态（暂存区清空，代码放回代码区）。

git reflog：用来记录你的每一次命令。

添加远程仓库

在GitHub上创建一个仓库，在本地仓库运行命令：
git remote add origin git@github.com:github账户名/.git
关联一个远程仓库。
关联后，使用命令：git push -u origin master 第一次推送分支master的所有内容
此后每一次提交后，只要有必要，就使用命令：git push origin master 推送最新修改
